# Sobre este livro

Este livro reúne as anotações do bootcamp **Banco Pan · Java Developer**, da **DIO (Digital Innovation One)**, reescritas em linguagem simples para quem está começando do zero e atualizadas para as versões atuais do Java (21/25) e do Spring Boot (3+).

## Como ler

- **Começando do zero?** Leia os módulos na ordem: Git e métodos ágeis, a linguagem Java, desafios, orientação a objetos, bancos de dados e, por fim, o Spring.
- Toda aula começa com um resumo **"Em uma frase"** e termina com **"Resumindo"** e exercícios **"🏋️ Mão na massa"**.
- As **respostas dos exercícios** ficam no fim de cada aula. Tente resolver antes de olhar!
- Os exemplos de código foram testados. Digite-os (em vez de copiar e colar): é a melhor forma de aprender.
- No final há dois **apêndices**: o guia rápido com glossário e um **simulado** com gabarito comentado.
- Use a **busca** do seu leitor de e-books para encontrar um comando, uma anotação ou um termo.
